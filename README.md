# Vişne Bahçesi

Burdur Tefenni Yeşilköy koşullarına odaklanan, vişne yetiştiriciliği hakkında uygulamalı bilgi ve bahçe takvimi sunan web sitesi.

## İlk sürüm

- Mobil uyumlu ana sayfa
- Budama, besleme ve bitki sağlığı rehberleri için içerik altyapısı
- Mevsimsel bahçe takvimi bölümü
- Erişilebilir mobil menü

Site saf HTML, CSS ve JavaScript ile hazırlanmıştır; ek kurulum gerektirmez.
